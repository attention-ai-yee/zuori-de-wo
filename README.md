# 分身大作战

2D 像素风解谜（和过去的自己合作），单个 `index.html`，浏览器直接打开就能玩。按手机解谜小游戏的习惯排版：棋盘占满屏幕，在棋盘上滑动移动、点自己原地等一步，底部一排圆形按钮（等待 · 留影 · 撤销），右上角是帮助和提示，顶部只有菜单、帮助和一个小小的关卡号，关卡名进关时在棋盘上淡入淡出，剩余影子数显示在「留影」按钮的角标上，右上角留空给微信胶囊。横向很长的关卡在竖屏上会自动转成竖向。电脑上显示成手机大小，也能用键盘。

**玩法**：在棋盘上滑动移动，点自己原地等一步。点「留影」，这一轮的你留下来变成影子，你回到起点重新出发；影子会原样重复你的每一步操作（撞墙也照撞）。踩住压力板开同色门；斜纹的是反向门，同色板被踩住时反而关上。钥匙只能被拿一次（影子也会抢），带着它走进锁门，门就永久打开。每关有影子名额上限。底部按钮有等待和撤销一步；右上角灯泡是提示（淡淡浮出一句提示，可演示解法），左上角「?」是规则说明；顶部有独立的重开按钮，菜单里可以分别开关音乐和音效（背景音乐是 WebAudio 现场合成的 16 小节 C 大调循环曲，带鼓点和回声）。通关有星级结算（总步数不超过参考解即三星）。界面只面向手机；代码里保留了键盘操作，方便在电脑上调试。
**新手引导**：第 1 关会一步步指给你看（走到压力板 → 点「留影」→ 去拿钻石）；第 2、5、6 关第一次出现反向门、等待、箱子、钥匙和锁门时，会弹出指向它的小气泡。过关一次后就不再出现。画面是明亮的天空蓝 + 奶油色格子地板，格子之间有清楚的分界线。


**21 关**：1–3 教学，4–16 逐关加难，17–21 是难关。回声 · 时机 · 接力 · 你先走 · 搬运 · 钥匙 · 节拍 · 抢先一步 · 进出 · 放手 · 钥匙在门里 · 推过去 · 交接班 · 往返 · 三件事 · 开门的人 · 绕路 · 互为钥匙 · 三人行 · 偷运 · 告别。

## 验证
- `node test/test.js`：用引擎跑每关的参考解，确认通关。
- `node test/solver.js [关号]`：BFS 求解器，证明「名额减一」时无解（影子的按键可以任选，所以 k 个影子 = k+1 个可自由操控的角色）。第 11、15 关角色多、状态太多，用 `test/solver_sym.js` 的对称剪枝版本验证。
- `node test/phone.test.js`：模拟 iPhone 通关全部关卡、测试中途转屏，并生成手机截图（screenshots/m*.png）。
- `node test/play.test.js`：Playwright 打开真页面，走真实输入路径通关全部关卡，并用键盘实玩第 1 关。
- 改关卡/引擎后在 `src/` 里跑 `python3 build.py` 重新生成 `index.html`。
