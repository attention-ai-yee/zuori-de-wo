# 分身大作战

2D 像素风解谜（和过去的自己合作），单个 `index.html`，浏览器直接打开就能玩。按手机解谜小游戏的习惯排版：棋盘占满屏幕，在棋盘上滑动移动、点自己原地等一步，底部一排圆形按钮（等待 · 留影 · 撤销），右上角是帮助和提示，顶部只有菜单、帮助和一个小小的关卡号，关卡名进关时在棋盘上淡入淡出，剩余影子数显示在「留影」按钮的角标上，右上角留空给微信胶囊。横向很长的关卡在竖屏上会自动转成竖向。电脑上显示成手机大小，也能用键盘。

**玩法**：在棋盘上滑动移动，点自己原地等一步。点「留影」，这一轮的你留下来变成影子，你回到起点重新出发；影子会原样重复你的每一步操作（撞墙也照撞）。踩住压力板开同色门；斜纹的是反向门，同色板被踩住时反而关上。每关有影子名额上限。底部按钮有等待和撤销一步；右上角灯泡是提示（淡淡浮出一句提示，可演示解法），左上角「?」是规则说明；菜单里可以重开本关、分别开关音乐和音效（背景音乐是 WebAudio 现场合成的循环小曲）。通关有星级结算（总步数不超过参考解即三星）。界面只面向手机；代码里保留了键盘操作，方便在电脑上调试。

**15 关**：回声(1) · 接力(2) · 时机(1) · 搬运(1+箱子) · 你先走(1) · 节拍(1) · 放手(2) · 交接班(2) · 推过去(1+箱子) · 开门的人(2) · 绕路(3) · 往返(1) · 三件事(1) · 互为钥匙(2) · 告别(3)。括号里是影子名额。前 5 关是教学关，之后逐步变难。每关用到的技巧见 [docs/关卡技巧.md](docs/关卡技巧.md)。

## 验证
- `node test/test.js`：用引擎跑每关的参考解，确认通关。
- `node test/solver.js [关号]`：BFS 求解器，证明「名额减一」时无解（影子的按键可以任选，所以 k 个影子 = k+1 个可自由操控的角色）。第 11、15 关角色多、状态太多，用 `test/solver_sym.js` 的对称剪枝版本验证。
- `node test/phone.test.js`：模拟 iPhone 通关全部关卡、测试中途转屏，并生成手机截图（screenshots/m*.png）。
- `node test/play.test.js`：Playwright 打开真页面，走真实输入路径通关全部 14 关，并用键盘实玩第 1 关。
- 改关卡/引擎后在 `src/` 里跑 `python3 build.py` 重新生成 `index.html`。
