# 昨日的我

2D 像素风时间回溯解谜，单个 `index.html`，浏览器直接打开就能玩。按手机竖屏小游戏来排版：顶部关卡栏，底部方向键和回溯键，横向很长的关卡在竖屏上会自动转成竖向；电脑上显示成手机框，也能用键盘。

**玩法**：方向键 / WASD 移动，空格原地等一步。按 **R** 把时间倒回本关开头，刚才的你变成影子，原样重复你按过的每个键（撞墙也照撞）。踩住压力板开同色门；斜纹的是反向门，同色板被踩住时反而关上。每关有影子名额上限。
Z 撤销一步（没步可撤时撤回上一次回溯），X 重走这一轮（影子保留），Esc 清空影子。卡关可以点「看解法」。

**14 关**：回声(1) · 接力(2) · 时机(1) · 搬运(1+箱子) · 游行(3) · 你先走(1) · 放手(2) · 交接班(2) · 绕路(3) · 我们(4) · 节拍(1) · 推过去(1+箱子) · 开门的人(2) · 告别(3)。括号里是影子名额。

## 验证
- `node test/test.js`：用引擎跑每关的参考解，确认通关。
- `node test/solver.js [关号]`：BFS 求解器，证明「名额减一」时无解（影子的按键可以任选，所以 k 个影子 = k+1 个可自由操控的角色）。第 10、14 关角色多的状态太多，用 `test/solver_sym.js` 的对称剪枝版本验证。
- `node test/phone.test.js`：模拟 iPhone 通关全部关卡、测试中途转屏，并生成手机截图（screenshots/m*.png）。
- `node test/play.test.js`：Playwright 打开真页面，走真实输入路径通关全部 14 关，并用键盘实玩第 1 关。
- 改关卡/引擎后在 `src/` 里跑 `python3 build.py` 重新生成 `index.html`。
